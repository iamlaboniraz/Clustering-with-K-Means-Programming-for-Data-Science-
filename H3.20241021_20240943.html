Clustering with K-Means¶

K-Means is one of the most popular "clustering" algorithms, which you perhaps are already familiar from the Data Mining curricular unit. K-means estimates the location of $k$ centroids that it uses to define clusters. A point is considered to be in a particular cluster if it is closer to that cluster's centroid than any other centroid.

The K-means Algorithm consists in an iterative process that is roughly as follows:

  1. Choose value for K (number of clusters);
  2. Initialize the locations of the centroids, which we can do by randomly select K points from your dataset as initial locations of the centroids;
  3. Calculate distance of all other points to each of the K centroids;
  4. Associate each point to the cluster of the closest centroid;
  5. Update the centroid position, by computing the average coordinates of all points associated to each cluster;
  6. Evaluate the average change in the centroids positions, as a measure of convergence (the algorithm is said to have converged to the solution when the positions of the centroids don't change more than a given tolerance threshold);
  7. Repeat steps 3-6 until either the centroids no longer move more than a tolerance threshold or until you repeated these steps at least for specified number of iterations (niter)

The algorithm is thus parametized by the number of clusters (K), the maximum number of iterations (niter), and the tolerance threshold (tol).

def generate_test_data(mean1, mean2, std, n_samples=100, seed=12):
    # Set the random seed for reproducibility
    if seed is not None:
        np.random.seed(seed)
    
    # Ensure the distance between means is at least 2 * std
    distance = np.linalg.norm(np.array(mean1) - np.array(mean2))
    if distance < 2 * std:
        raise ValueError("The distance between means must be at least 2 * standard deviation.")
    
    # Generate points for two clusters
    points_cluster1 = np.random.normal(loc=mean1, scale=std, size=(n_samples // 2, 2))
    points_cluster2 = np.random.normal(loc=mean2, scale=std, size=(n_samples // 2, 2))
    
    # Combine both clusters into one array
    points = np.vstack((points_cluster1, points_cluster2))
    return points

def centroid_update(points, clusters):
    # Number of clusters define, assuming clusters are labeled from 0 to k-1
    k = np.max(clusters) + 1
    # print(k)
    # Define initial centroids array, and value are 0 initially
    centroids = np.zeros((k, points.shape[1]))
    # print("initial centroids", centroids)
    for k in range(k):
        # print("k and clusters", k,clusters)
        # select points in clusters k
        cluster_points = points[clusters == k]
        if len(cluster_points) > 0: # Avoid division by zero if a cluster has no points
            centroids[k] = np.mean(cluster_points, axis=0)
    return centroids

def points_update(points, centroids):
    closest_centroid = []
    
    # interate over each point
    for point in points:
        
        # Compute the distance between the current poin and each centroid
        distances = np.array([distance(point, centroid) for centroid in centroids])
        
        # find the index of nearest centroid
        closest_centroid_index = np.argmin(distances)
        
        # append this to the list
        closest_centroid.append(closest_centroid_index)
    
    # convert the list into np array
    return np.array(closest_centroid)

def error(oldcentroids, newcentroids):
    avg_euclidean = []
    # interate over each centroid
    for i in range(len(oldcentroids)):
        #compute the euclidean distance
        dist = distance(oldcentroids[i],newcentroids[i])
        avg_euclidean.append(dist)
    # return the average distance between centroids    
    return np.mean([avg_euclidean])

# You may adjust these values based on data size and clustering requirements.
"""
def kmeans(points, k=2, tol=1e-4, niter=100):
    # Step 1: Initialize centroids randomly from the points
    centroids = points[np.random.choice(points.shape[0], k, replace=False)]

    # Step 2: Initialize variables for tracking iteration and convergence
    prev_centroids = np.zeros_like(centroids)
    iter_count = 0

    # Iterate until convergence or maximum iterations reached
    while np.linalg.norm(centroids - prev_centroids) > tol and iter_count < niter:
        # Step 3: Assign each point to the closest centroid
        distances = np.linalg.norm(points[:, np.newaxis] - centroids, axis=2)
        clusters = np.argmin(distances, axis=1)

        # Step 4: Store current centroids and compute new centroids
        prev_centroids = centroids.copy()
        centroids = np.array([points[clusters == i].mean(axis=0) for i in range(k)])
        
        # Increment iteration counter
        iter_count += 1

    return clusters, centroids

def inertia(points, clusters, centroids):
    # Number of clusters given by the shape[0] rows.
    num_clusters = centroids.shape[0]
    
    # Calculate the squared distances from each point to the centroid of its cluster
    squared_distances = np.array([distance(points[i], centroids[clusters[i]]) ** 2 for i in range(points.shape[0])])
    
    # Calculate the average squared distance
    average_squared_distance = np.mean(squared_distances)
    
    return num_clusters, average_squared_distance
